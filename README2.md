# Завдання 20

Напишіть функцію для генерації псевдовипадкових часових рядів з автокореляцією для прогнозування енерго споживання.
Оцініть властивості згенерованих даних за допомогою функції автокореляції та графіків для порівняння з реальними часовими рядами.

## Пакети

  numpy
  matplotlib
  statsmodels


## Логіка роботи програми

1.Імпортуються бібліотеки numpy, matplotlib та statsmodels для генерації даних, побудови графіків та обчислення автокореляції.

2.Визначається функція generate_time_series, яка створює AR(1) часовий ряд з шумом і автокореляцією.

3.Генерується часовий ряд із заданою довжиною та коефіцієнтом автокореляції (phi).

4.Обчислюється автокореляційна функція (ACF) для оцінки залежності значень ряду від попередніх.

5.Будуються графіки: часовий ряд та його ACF для візуального аналізу.

6.Опціонально, порівнюються різні ряди за ACF, щоб показати вплив різних коефіцієнтів автокореляції.

Згенерований часовий ряд демонструє властивості автокорельованого процесу: при високому коефіцієнті phi = 0.8 значення ряду змінюються плавно і сильно залежать від попередніх, що видно на графіку часового ряду та через повільне спадання автокореляційної функції (ACF). Ряд із меншим phi = 0.5 показує швидше зниження автокореляції і більш шумні коливання, що відображає меншу “пам’ять” ряду. Порівняння графіків ACF різних рядів дозволяє оцінити вплив параметрів моделі на структуру даних і дає можливість наблизити згенеровані ряди до реальних часових рядів енергоспоживання для подальшого прогнозування.
