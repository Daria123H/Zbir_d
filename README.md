# Завдання 20

Дана програма написана для оцінки якості даних, отриманих у результаті збору інформації з файлу CSV. Вона аналізує набір даних та обчислює основні показники якості, а також загальний індекс якості скрейпінгу. Програма реалізована мовою Python з використанням бібліотеки pandas.

## Вхідні дані

Вхідним файлом є CSV-файл PR1.csv, який містить такі колонки, як title, price, date. Файл зчитується з локального шляху:

          
    D:\Збір даних\Пр1\PR1.csv


## Логіка роботи програми

1.Зчитує CSV-файл у DataFrame.

2.Визначає загальну кількість рядків у наборі даних.

3.Обчислює частку пропущених значень у всій таблиці.

4.Перевіряє колонку price: перетворює значення на числові; визначає частку нечислових значень.

5.Перевіряє колонку date: перетворює значення у формат дати; визначає частку некоректних дат.

6.Визначає частку дублікатів рядків.

7.Обчислює індекс якості скрейпінгу як середнє значення всіх показників якості

## Формула індексу якості

      quality_index = 1 - (missing_share +
                           non_numeric_price_share +
                           invalid_date_share +
                           duplicates_share) / 4
