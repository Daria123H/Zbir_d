## Пакети

pandas — для створення, обробки та збереження табличних даних.

numpy — для генерації великих масивів випадкових числових даних.

time — для вимірювання часу виконання операцій читання та запису.

sqlite3 — для роботи з базою даних SQLite у форматі SQL.

matplotlib.pyplot — для побудови графіків порівняння продуктивності різних форматів збереження даних.


## Логіка роботи програми

1. Генерація даних

Спочатку створюється штучний набір даних обсягом 1 000 000 записів, який моделює енергетичні показники:

timestamp — час вимірювання;

consumption_kwh — споживання електроенергії;

voltage — напруга;

current — сила струму.

2. Вимірювання продуктивності

Для кожного формату реалізовано функції, які вимірюють:

час запису даних;

час зчитування даних.

Використовується модуль time, який фіксує різницю між початком і завершенням операції.

3. Збереження у різних форматах

Дані послідовно зберігаються у таких форматах:

CSV — простий текстовий формат;

Parquet — колонковий формат, оптимізований для швидкості;

HDF5 — бінарний формат для великих наукових даних;

SQL (SQLite) — збереження у реляційній базі даних.

Для SQL використовується база даних SQLite, у яку таблиця записується через to_sql().

4. Зчитування даних

Після запису дані з кожного формату зчитуються назад у DataFrame для вимірювання часу читання.

5. Порівняння результатів

Результати записуються у спільну структуру даних (results), яка містить:

формат збереження;

час запису;

час читання.

6. Візуалізація

На основі отриманих результатів будується стовпчикова діаграма, яка порівнює швидкість:

запису даних;

читання даних.

Графік дозволяє наочно оцінити продуктивність кожного формату.
