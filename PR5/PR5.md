# Завдання 20

Обробка зображень: Написати код для обробки зображень, наприклад, для виділення контурів об&#39;єктів у зображенні за допомогою бібліотеки opencv.

## Пакети

cv2 (OpenCV) — основна бібліотека для обробки зображень, що надає інструменти для перетворення кольорів, фільтрації, розмиття та виділення контурів.

PIL (Pillow) — використовується для зчитування та попередньої обробки зображень у зручному форматі.

NumPy — застосовується для роботи з масивами даних та перетворення зображення у формат, сумісний з OpenCV.

## Логіка роботи програми

Програма виконує обробку зображення з метою виділення контурів об’єктів на ньому.

Спочатку зображення завантажується за допомогою бібліотеки PIL, після чого конвертується у формат RGB. Далі воно перетворюється у масив NumPy та переводиться у формат, який підтримує OpenCV (BGR).

Наступним етапом є переведення зображення у відтінки сірого, що спрощує подальшу обробку. Після цього застосовується Gaussian Blur для зменшення шумів та покращення якості виділення контурів.

Для визначення контурів використовується алгоритм Canny edge detection, який знаходить різкі зміни інтенсивності пікселів та формує контури об’єктів на зображенні.

У результаті програма відображає вікно з виділеними контурами зображення.
