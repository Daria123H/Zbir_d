# Завдання 20

Вивчення впливу магнітного поля на роботу побутових пристроїв. Потрібно виміряти рівень магнітного поля поблизу різних побутових пристроїв, таких як комп&#39;ютери, телевізори, мікрохвильові печі, і оцінити їхній вплив на інші пристрої. Обробка даних включає порівняння рівнів магнітного поля та виявлення взаємозв'язків.

## Пакети

pandas — для зчитування даних з Excel-файлів та їх обробки у вигляді таблиць

matplotlib.pyplot — для побудови графіків і візуалізації результатів

openpyxl / xlrd — для роботи з Excel-файлами (залежно від формату .xlsx або .xls)

А також для Phyphox отримання даних з датчиків телефону.

## Логіка роботи програми

Програма призначена для аналізу магнітного поля, виміряного поблизу різних побутових пристроїв.

На першому етапі здійснюється зчитування експериментальних даних з Excel-файлів за допомогою бібліотеки pandas. Кожен файл містить значення магнітного поля по трьох осях (x, y, z), а також обчислене абсолютне значення магнітного поля.

Далі з усіх даних обирається колонка Absolute field (µT), яка використовується для основного аналізу, оскільки вона відображає загальну величину магнітного поля незалежно від напрямку.

На наступному етапі виконуються обчислення середніх значень магнітного поля для кожного пристрою, що дозволяє порівняти рівень випромінювання між ними.

Після цього будується графік залежності магнітного поля від часу для кожного пристрою, що дає можливість проаналізувати зміну показників у процесі вимірювання.

Також створюється порівняльна діаграма середніх значень магнітного поля, яка наочно демонструє, який із пристроїв створює найбільший рівень магнітного випромінювання.

У результаті виконання програми отримуються числові характеристики та графічні залежності, що дозволяють зробити висновки щодо впливу побутових пристроїв на магнітне середовище. Було виміряно магнітне поле поблизу ноутбука, мікрохвильової печі та холодильника за допомогою Phyphox (magnetometer). Отримані дані показали, що всі пристрої створюють магнітні поля порядку десятків мікротесла, що порівнянно з магнітним полем Землі. Найвищі середні значення зафіксовано біля ноутбука (54.3 µT), найнижчі — біля холодильника (41.1 µT). Мікрохвильова піч демонструє найбільші коливання значень під час роботи, що вказує на змінний характер її електромагнітного випромінювання. Таким чином, найбільший потенційний вплив на інші пристрої має мікрохвильова піч, тоді як холодильник має найменший вплив.
